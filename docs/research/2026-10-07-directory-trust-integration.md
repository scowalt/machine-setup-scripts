## Closure and containment

The new combined Ubuntu/macOS caller retains **real Backlog retirement, Pi profile preparation, Pi prose retirement and Impeccable convergence**, with all unrelated effects inert. Captured Impeccable directories stay 0775; HOME/selected ancestors/npm containers stay 02775; Pi leaves stay 0700. It verifies final artifact/metadata changes, unrelated credential/custom-style sentinels, repeat convergence and directory metadata preservation. A real writable Backlog metadata-file refusal survives later real successes; an actual inert-installer failure survives earlier successful operations and final reboot/log reporting. This complements, rather than replaces, the per-slice real caller/deferral/recovery matrices.

The audit found plugin-refresh's Python suite was not selected by the all-shell dispatcher. A thin `bb-plugin-refresh-contract.sh` now includes it; the new combined contract is also discovered automatically. No production test interface or whole-source loader was added. The dispatcher passes a bounded **900-second per-suite** timeout: the expanded Impeccable convergence suite completed in 340.7 seconds (38 methods with repeated multi-layout/provider lifecycle cases), not a stuck native operation. Its callers took 160.4 seconds. The previous 300-second deadline was insufficient. Kernel/FD enforcement, mandatory self-test, sequential execution and timeout process-group termination are unchanged; `tests/run-fixture-matrix.py`, `tests/fixture-no-network.c` and `tests/extract_setup_fixture.py` remain byte-identical to initial `75fc596`.

Read the [execution audit](2026-09-29-fixture-execution-audit.md) and [incident](2026-09-29-fixture-containment-incident.md) before every new behavioral path. Reviewed definitions-only/AST loaders and inert effect boundaries before running; combined operations use the existing copied-runtime fixture and child-process/privacy/permission-repair traps. Verified `test_native_npm_tarball_and_prefix_abi_transition` uses `shutil.copy2` for both old/new Node prefixes, as fixed by #210 before its tests. Remaining native-tool links are command selectors, fixture-internal links or refusal inputs, not real installations exposed as writable prefixes. Optional installed-code and external-dotfile controls stay absent.
