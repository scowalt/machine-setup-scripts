# Verify source-built OpenCode against official Homebrew bottles

The October 23 Mac failure exposed a distribution mismatch: the installed `homebrew/core` OpenCode `1.18.30_2` binary (SHA-256 `9bb8916294e3ad42c7db707132018abd533a7cae700fcaccaec44bbc6ac693c1`) exactly matched Homebrew's `arm64_golden_gate` bottle, whose formula builds from source with a build workaround, but differed from every accepted npm binary. After npm identity fails, the [shared verifier](../../lib/opencode-cli.cjs) may identify only recognized core Homebrew copies through the exact keg's public GHCR index, platform-specific manifest and bottle digest, then compare the executable bytes without filesystem extraction or execution; a local receipt alone is never sufficient. This adds bounded anonymous-pull authentication and one digest-specific public-CDN redirect with credentials stripped, rather than an installation-specific hash exception or relaxed content checks; unmatched or relocated bytes still fail closed, and [command-only migration](0004-keep-opencode-migration-command-only.md), pins, newer copies, snapshots and recovery remain unchanged.
